Capabilities

Powerful Features

Every capability OpenDroid brings to your Android device — built for autonomy, designed for privacy.

Habit & Routine Detection

New in v1.0.6

OpenDroid notices your repeated daily patterns — like opening Gmail, checking Calendar, and opening Slack every weekday at 9:00 AM. After detecting a pattern, it proactively asks: "I noticed you usually do these tasks every weekday morning. Would you like me to automate them?" One tap converts the routine into a scheduled background macro with morning briefings.

HabitRoutineEngine Sequence Mining Morning Briefing Macro Bridge

Telegram & WhatsApp Automation

Enhanced in v1.0.6

Full hands-free control across messaging apps. Send Telegram messages to @username handles, address book contacts, or international phone numbers without opening the app manually. Also automates WhatsApp chat and group messages, SMS drafting, and phone calls with graceful intent fallbacks.

SEND_TELEGRAM SEND_WHATSAPP TelegramAutomator ContactResolver

Screen Understanding ("Read & Remember")

v1.0.5

Tell OpenDroid: "Read this screen and save the meeting details to my notes" or "Remember this". Multimodal vision and accessibility trees extract structured event data (title, date, location, participants, action items) into persistent memory. Retrieve anything later by asking: "What did I save about the flight?"

READ_AND_REMEMBER_SCREEN RECALL_MEMORY Multimodal Vision

4-Tier Personal Knowledge Graph

OpenDroid retains intelligence safely across four distinct tiers: Level 1 (Temporary) for active plan context; Level 2 (Long-Term) for explicit facts and preferences; Level 3 (Learned Patterns) for inferred habits with dynamic confidence scoring; and Level 4 (Sensitive Data) encrypted with hardware Android Keystore AES-256-GCM.

PersonalGrowthEngine Dynamic Confidence Keystore AES-256 Room SQLite

Autonomous Planning & Re-evaluation

Give OpenDroid a complex, multi-step goal like "Check if it's going to rain, text my wife I'll be late, and set an alarm for 6 PM". The agent decomposes commands into logical sub-tasks, executes each in sequence, verifies the outcome, and dynamically adjusts the remaining steps if something fails or conditions change.

PlanManager ReEvaluationEngine IntentClassifier Compound Intent Guard

Full Device & System Control

Deep integration with Android system APIs enables control over brightness, Wi-Fi, Bluetooth, flashlight, screen lock, alarms, timers, calendar events, currency conversions, media playback, and hardware status — all locally and hands-free.

SystemActions WRITE_SETTINGS AlarmManager CalendarProvider

On-Device AI Models (LiteRT-LM)

Run 100% offline with zero cloud dependency. Download LiteRT models (Gemma 4 e2b-it, Qwen 2.5, Llama 3.2) in the background via WorkManager over Wi-Fi or cellular networks. Downloads verify SHA-256 checksums and test runtime JNI compatibility before enabling on-device inference.

LiteRT-LM Offline AI Hugging Face Auth WorkManager

Accessibility Automation

When API controls aren't available, OpenDroid leverages Android's Accessibility Service to interact with third-party apps directly. It can click buttons, scroll feeds, read screen layouts, type text, and navigate complex UIs across your favorite apps.

AccessibilityService UI Automation Node Scraping Gesture Injection

10+ LLM Provider Support

Bring your own AI model. OpenDroid supports Anthropic Claude, OpenAI GPT, Google Gemini, Groq, Mistral, OpenRouter, Together AI, Cohere, DeepSeek — and offline execution via local Ollama or LiteRT models. Features dynamic runtime model discovery straight from provider endpoints.

Anthropic OpenAI Gemini Ollama Dynamic Fetch
